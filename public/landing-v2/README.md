# Decisionary Landing V2

Static landing-page prototype kept outside the Next app so it does not mix with the product routes.

Open `index.html` directly in a browser, or serve this folder with any static server.

`privacy.html` contains the landing-page privacy notice used from the demo request form and footer.

Positioning shift:

- From generic tabletop/AAR promise.
- To live crisis decision room: Updates, Pulse, decisions, escalations, follow-up tasks, and reviewable trace.
- The page is English-only for now to keep positioning and maintenance focused.
